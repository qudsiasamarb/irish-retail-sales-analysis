# irish-retail-sales-analysis
SQL and Power BI analysis of Irish retail sales using official CSO Ireland data

An end-to-end **SQL and Power BI analytics project** analysing Irish retail performance using official **Central Statistics Office (CSO) Ireland** data.

## Project Overview

This project analyses more than **13,000 retail observations** from CSO Ireland, covering:

- Retail Sales Index
- Retail value and volume trends
- Year-over-Year and Month-over-Month growth
- Sector performance
- Online sales share
- Seasonal retail patterns

The data covers retail activity up to **June 2026**.

## Tools Used

- MySQL
- SQL
- Power BI
- Power Query
- DAX
- CSO Ireland Open Data

Analysis of:

## Key Insights

- Motor Trades recorded the strongest average YoY volume growth over the latest 12 months at approximately **5.15%**.
- Textiles, Clothing & Footwear recorded the largest YoY increase in online-sales share at approximately **+1.1 percentage points**.
- December showed the strongest seasonal retail activity, with an average unadjusted Retail Value Index of approximately **140.6** during 2021–2025.
- Retail sectors displayed significantly different levels of monthly volatility.

## Data Source

**Central Statistics Office (CSO) Ireland**

Datasets:
- RSM08 – Retail Sales Index
- RSM07 – Online Sales Share
